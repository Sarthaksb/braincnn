[MEMBER 1 SCRIPT: INTRODUCTION & PROBLEM STATEMENT]
"Good morning, respected teachers and external examiners. Our project is titled
'Brain Tumor Classification using Deep Learning and CNN'. It is an automated
diagnostic system that takes a brain MRI scan image as input and accurately detects
whether a tumor is present, and if present, classifies its exact clinical type.

Brain tumors are among the most lethal neurological diseases. In traditional medical
practice, radiologists analyze hundreds of MRI scan slices manually. This manual
process has two major limitations: it is time-consuming (causing diagnostic delays
in critical cases), and it is prone to human error, especially in rural clinics
where specialized neuro-radiologists are unavailable.

Our primary objective was to build an automated, deep learning system using Transfer
Learning to provide doctors with a reliable, second-opinion diagnostic tool in
under 1 second."


[MEMBER 2 SCRIPT: DATASET, CLASSES & PREPROCESSING]
"For training and evaluating our model, we used the benchmark Brain Tumor
Classification MRI dataset curated by Sartaj Bhuvaji on Kaggle. It contains
3,264 MRI images organized into a Training set (2,870 images) and a Testing set
(394 images).

The dataset covers 4 distinct categories:
1. Glioma Tumor: Cancerous tumors originating in the glial tissue of the brain.
2. Meningioma Tumor: Slow-growing, mostly benign tumors arising from brain membranes.
3. Pituitary Tumor: Abnormal growths at the base of the skull in the pituitary gland.
4. No Tumor: Healthy brain MRI scans with no tumor tissue.

Before feeding images into our neural network, we applied three vital preprocessing steps:
• Resizing: Standardized all scans to 224 x 224 pixels with 3 RGB channels.
• Normalization: Divided pixel values by 255.0 to scale them into [0, 1] for faster
  gradient convergence.
• Data Augmentation: Applied zoom (20%), shear (20%), and horizontal flips using Keras
  ImageDataGenerator to prevent overfitting and help the model generalize."


[MEMBER 3 SCRIPT: DEEP LEARNING ARCHITECTURE & DENSENET201]
"We implemented Transfer Learning using the DenseNet201 (Densely Connected
Convolutional Network) architecture pre-trained on ImageNet.

Why DenseNet201? In traditional CNNs, layers connect only sequentially. In DenseNet,
each layer receives feature maps from all preceding layers. This completely eliminates
the vanishing gradient problem, promotes feature reuse, and yields superior accuracy
with fewer parameters.

Architecture of our custom classifier head:
1. Frozen Base: We set layer.trainable = False on the DenseNet201 backbone to retain
   pre-trained ImageNet feature extractors.
2. Flatten Layer: Converts 2D feature maps into a 1D feature tensor.
3. Dense Layer (256 neurons, ReLU): Learns high-level tumor discrimination patterns.
4. Dropout (0.3): Deactivates 30% of neurons during training to prevent overfitting.
5. Output Dense Layer (4 neurons, Softmax): Outputs probability distribution summing
   to 1.0 across all 4 classes.

The model is compiled with Categorical Crossentropy loss and the RMSprop optimizer
with a learning rate of 0.00001."

6. EXTERNAL EXAMINER VIVA Q&A CHEAT SHEET
--------------------------------------------------------------------------------
Q1: What is Transfer Learning?
Answer: Transfer Learning means taking a network that was already trained on a massive
dataset (ImageNet with 1.4M images) and fine-tuning it for our specialized medical task.
This eliminates the need for millions of medical images and saves days of training time.

Q2: Why DenseNet201 instead of VGG16 or ResNet50?
Answer: DenseNet connects each layer to every other layer in a feed-forward manner.
This allows maximum feature reuse, avoids vanishing gradients, and requires fewer
parameters than ResNet or VGG while achieving higher accuracy.

Q3: Why Softmax activation for the output layer?
Answer: Softmax converts the model's raw numerical outputs into probability values
between 0.0 and 1.0 that sum up to exactly 1.0 (100%), which is mathematically
required for mutually exclusive multi-class classification.

Q4: What is the purpose of Dropout (0.3)?
Answer: Dropout randomly turns off 30% of neurons during each training step. This
forces the remaining neurons to learn independent features and prevents the model
from overfitting or memorizing the training data.

Q5: Why is the .h5 file not displayed in a text editor?
Answer: The .h5 (Hierarchical Data Format 5) file is a compiled binary file containing
42.4 million 32-bit floating-point numbers representing neural network weights and
biases. It cannot be opened as text; it is loaded directly into RAM by TensorFlow.

Q6: What is the difference between Glioma and Meningioma?
Answer: Gliomas originate inside the brain from glial cells and are often malignant
(cancerous). Meningiomas originate from the meninges (the membranes covering the brain)
and are mostly benign (non-cancerous) and slow-growing.

Q7: Why normalize pixel values by 1/255?
Answer: Raw image pixels have integer values from 0 to 255. Dividing by 255.0 scales
them into the floating-point range [0.0, 1.0]. This prevents large weight updates,
stabilizing gradient descent during training.
